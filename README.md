# 📊 GitHub Profile Card Maker

A lightweight Java GUI application that connects to the GitHub REST API to fetch and display real-time profile statistics for any GitHub user.

## 🚀 Features
- **Live API Integration:** Fetches real-time public repository counts directly from GitHub servers.
- **Multithreaded:** Runs internet requests asynchronously to keep the UI smooth and responsive.
- **Built with Native Java:** Uses Java Swing and standard HTTP connection libraries with zero external dependencies.

## 🛠️ Built With
- **Language:** Java 17+
- **GUI Framework:** Java Swing
- **API:** GitHub REST API (`https://api.github.com/users/`)
